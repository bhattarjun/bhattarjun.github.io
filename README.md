# 🚀 Arjun's Dev Canvas

A modern, high-performance portfolio website showcasing my experience as a Full-Stack Software Engineer. Designed with a clean developer-first aesthetic, this portfolio highlights my technical expertise, professional journey, and real-world projects while remaining easy to scan for recruiters and clients.

This is a single-page, responsive portfolio built to present my skills, experience, and projects in a visually engaging and professional manner.

The design focuses on:

- 💼 Recruiter-friendly layout
- 🚀 Professional personal branding
