# Arjun Bhatt: Full Stack Showcase

Build a modern, bright, and visually striking developer portfolio website for a Full Stack Software Engineer named Arjun Bhatt.

GOAL: The site must impress two very different audiences at once — corporate HR/recruiters scanning fast for keywords and credibility, AND potential freelance clients evaluating trust and project quality. So it needs to feel premium, fast, credible, and personal — not a generic template.

STYLE DIRECTION:

- Bright, clean, modern SaaS-startup aesthetic — NOT dark hacker-terminal cliché

- Bold accent color (electric blue or vivid indigo) against white/off-white base, with soft gradient accents

- Strong, confident typography (large hero headline, generous whitespace)

- Subtle scroll-triggered animations (fade/slide-in), smooth micro-interactions on hover

- Fully responsive, mobile-first

- Should NOT look like a stock Bootstrap template — give it a distinct visual identity (custom shapes, asymmetric layout accents, subtle grid/mesh background in hero)

PAGES / SECTIONS (single-page scroll with anchor nav, or light multi-page — your call, favor single-page):

1. Navbar — sticky, logo/name left, links: About, Skills, Experience, Projects, Resume, Contact

2. Hero — Name "Arjun Bhatt", title "Full Stack Software Engineer | .NET Core & React/Next.js", short 1-line value pitch, location, CTA buttons ("Download Resume" + "Let's Talk"), circular profile photo placeholder (user will upload own photo), social icons (LinkedIn, GitHub, Twitter/X)

3. About — short bio: full-stack engineer, ~4 years experience, backend in C#/.NET Core/ASP.NET MVC/Web API + MS SQL Server/PostgreSQL, frontend in React.js/Next.js/Angular, deploys and hosts on Microsoft Azure

4. Skills — grouped as cards or tags: Languages (C#, JavaScript, HTML5, CSS3, PHP), Backend (.NET Core, ASP.NET MVC, ASP.NET Web API, Node.js), Frontend (React.js, Next.js, Angular, React Native, jQuery, Bootstrap), Databases (MS SQL Server, PostgreSQL, MySQL), Cloud/DevOps (Microsoft Azure, Git, GitHub, GitLab), APIs (REST APIs, ChatGPT API integration)

5. Experience — vertical timeline component:

   - Software Engineer @ Pozitive Energy (Jan 2026 – Present)

   - Software Engineer (promoted from Associate SE) @ Prioxis Technologies Pvt. Ltd. (Aug 2022 – Dec 2025)

   - Associate Software Engineer @ Casepoint LLC (May 2022 – Jun 2022)

   Each with 2-3 bullet highlights.

6. Projects — grid of cards, each with title, tech-stack tags, short description, and a "view details" hover state. Include: Business CRM System, Tracker Flow (Maintenance Planning), Microsoft Teams AI Chatbot, Employee Management System, Kunto Light Mobile App, Prioxis Corporate Web Platform, Event Ticket Booking Platform, Hotel Room Booking System

7. Education — two entries: MCA, Atmiya University (2020–2022), BCA, Bhakta Kavi Narsinh Mehta University (2018–2021)

8. Resume section — embedded preview + prominent "Download Resume PDF" button

9. Contact — form (name, email, message) + direct email/phone display + social links; make it feel easy for a client to reach out, not just a corporate form

TECHNICAL:

- Build in React + Tailwind CSS

- Use Framer Motion (or similar) for scroll animations

- Fully responsive breakpoints for mobile/tablet/desktop

- Fast load, optimized images, semantic HTML for SEO

- Include placeholder for uploading a personal profile photo in the hero and about section

- Meta tags for SEO: title "Arjun Bhatt — Full Stack Software Engineer", description mentioning React, Next.js, .NET Core

TONE: Confident, credible, modern — like a senior engineer's personal brand site, not a student portfolio template.
